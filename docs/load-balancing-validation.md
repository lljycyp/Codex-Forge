## 测试中发现并处理的问题

- 初版拒绝所有加密推理，导致桌面工具返回后中断。已改为原样透传，并增加包含加密推理的工具历史回归用例。
- 启动独立客户端时不应继承父 Codex 的任务 ID、控制管道等环境变量，现已清理。
- 重启独立客户端时保留其模型、沙箱及桌面设置，只更新 Forge 服务地址。
- Windows 沙箱下初次读取测试文件被拒绝；获得权限后的下一轮成功。网关不会自动扩大客户端权限。

## 验证限制

- 第一轮结束时文件哈希检查不一致，默认配置的修改时间也有变化；该轮未保存逐文件差异，未确认修改来源，因此不宣称整个验收期间所有文件始终未变。第二轮单独记录基线并完成一致性检查。
- 直接调用上游 /responses/compact 返回 404，未实现服务端压缩块兼容。客户端文本压缩通过不代表该接口可用。
- 未验证 WebSocket、服务端会话 ID、文件 ID、图片上传、所有插件或所有模型与账号组合。
- 不做失败请求自动重放；未增加令牌自动刷新和满载排队。过期账号仍需通过现有账号管理刷新或重新授权。
- 桌面端验收使用 prepare_client 生成的真实配置；启动按钮的 IPC、目录选择及参数通过自动测试检查。没有替换已安装的 Forge，也没有重启用户原来的 Codex。
